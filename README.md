# Image Optimization & Bulk Processing

A Python automation tool designed to process
large batches of images efficiently.

## Features

- Bulk image renaming
- Automatic image organization
- Image resizing
- Image compression
- WebP conversion
- Duplicate filename handling
- Custom folder structures

## Technologies

- Python
- Pillow
- OS Module

## How to Run

1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Configure input and output folders.
4. Run:

   python main.py

## Project Purpose

This project automates repetitive image
processing tasks for e-commerce and
digital product workflows.
